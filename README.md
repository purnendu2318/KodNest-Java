## 🚀 How to Run the Code

1. **Clone the repository:**
   ```bash
   git clone https://github.com/purnendu2318/KodNest-Java.git
   cd KodNest-Java
   ```

2. **Navigate to the source directory:**
   ```bash
   cd track/M01-understanding-java/T01-programming-languages-and-java/M01-T01-ST01-L-welcome-to-java-track/work/src
   ```

3. **Compile and run any Java file:**
